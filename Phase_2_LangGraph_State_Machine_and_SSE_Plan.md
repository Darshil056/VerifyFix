# Phase 2 Implementation Plan: LangGraph State Machine & Flask Streaming Engine

## 1. Overview & Objectives
Phase 2 establishes the core orchestration engine of VerifyFix. It defines the shared typed state across all AI agents, constructs the state machine graph, and implements a Flask Server-Sent Events (SSE) streaming engine to broadcast real-time state deltas to the frontend.

---

## 2. Technical Specifications

### 2.1 State Definition (`backend/agents/state.py`)
Define the strictly typed dictionary representing the pipeline's execution state:

```python
from typing import TypedDict, List, Dict, Any, Optional

class VulnerabilityCandidate(TypedDict):
    cwe_id: str
    vulnerability_name: str
    file_path: str
    line_start: int
    line_end: int
    suspect_code: str
    reasoning: str

class RemediationItem(TypedDict):
    cwe_id: str
    vulnerability_name: str
    root_cause: str
    patch_diff: str
    defense_in_depth: str

class VerifyFixState(TypedDict):
    scan_id: str
    repo_owner: str
    repo_name: str
    branch_name: str
    target_diff: str
    candidate_vulns: List[Dict[str, Any]]      # Populated by Agent 1
    rag_context: Dict[str, str]                # Populated by Layer 2 RAG
    pruned_vulns: List[Dict[str, Any]]         # Filtered by Critic Agent Phase I
    generated_fixtures: Dict[str, str]         # Code generated by Critic Agent Phase II
    docker_status: Dict[str, str]              # State: SECURE | VULNERABILITY_CONFIRMED | HARNESS_ERROR
    harness_error_traces: Dict[str, str]       # Captured stderr traces for retry loop
    retry_count: int                           # Max retry loop limiter (e.g., max 3)
    final_remediations: List[Dict[str, Any]]   # Formatted by Senior Analyst Agent
    execution_step: str                        # Active DAG node: DISCOVERY | RAG | CRITIC | SANDBOX | RETRY | REMEDIATION | COMPLETED
    logs: List[str]                            # Live execution logs
```

### 2.2 LangGraph State Machine Graph (`backend/agents/graph.py`)
The pipeline runs an 8-stage directed acyclic graph with a conditional feedback edge:

```
[Start]
   │
   ▼
[node_github_ingest]
   │
   ▼
[node_discovery] (Agent 1: Gemini 2.5 Flash)
   │
   ▼
[node_rag] (Layer 2: ChromaDB MITRE CWE Ingestion)
   │
   ▼
[node_critic] (Agent 3: Triage & Fixture Generator) ◄────────┐
   │                                                         │ (HARNESS_ERROR &
   ▼                                                         │  retry_count < 3)
[node_sandbox] (Docker / Isolated Process Harness) ──────────┘
   │
   ├─► (VULNERABILITY_CONFIRMED / SECURE)
   │
   ▼
[node_remediation] (Agent 4: Senior Analyst)
   │
   ▼
[node_complete]
```

#### Conditional Edge Logic:
```python
def should_retry(state: VerifyFixState) -> str:
    statuses = state.get("docker_status", {}).values()
    if "HARNESS_ERROR" in statuses and state.get("retry_count", 0) < 3:
        return "retry_critic"
    return "proceed_to_remediation"
```

### 2.3 Flask Server-Sent Events (SSE) Engine (`backend/app.py`)
- Endpoint: `GET /api/scan/stream?scan_id=<ID>`
- Response Header: `Content-Type: text/event-stream`, `Cache-Control: no-cache`
- Event Format:
```
event: node_update
data: {"step": "node_critic", "status": "running", "timestamp": "2026-09-04T14:10:00Z"}

event: log
data: {"message": "[Critic Agent] Synthesizing SQLite in-memory test fixture for CWE-89..."}

event: state_delta
data: {"candidate_vulns": [...], "execution_step": "CRITIC"}
```

## 3. Implementation Steps

1. **Create `backend/agents/state.py`**: Define `VerifyFixState` with full typing.
2. **Create `backend/agents/graph.py`**: Assemble the LangGraph / DAG executor with generator yielding SSE-compatible events.
3. **Update `backend/app.py`**:
   - Implement `POST /api/scan/start` to register a new scan.
   - Implement `GET /api/scan/stream` with `Response(stream_with_context(...), mimetype='text/event-stream')`.
4. **Create `backend/tests/test_dag.py`**: Unit tests verifying node traversal and retry-count limits.
